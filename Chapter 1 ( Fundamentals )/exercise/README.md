# Chapter 1 - Exercises

This folder contains short exercises for the first chapter of the course.

## How to use

- Read the exercise statements in this file.
- Write your answers in `attempts.py`.
- Check the correction in `correction.md` only after trying the exercises.

## Exercise 1 - Variables, types, input/output

1. Create a variable `prenom` containing your first name.
2. Create a variable `age` containing your age.
3. Display a sentence that shows your name and age.
4. Ask the user for their favorite city and display it.

## Exercise 2 - Operators and control flow

1. Ask the user for two numbers.
2. Display their sum, difference, product, and quotient.
3. Ask for a grade and display:
   - "Très bien" if the grade is 16 or more
   - "Passable" if the grade is between 10 and 15
   - "Insuffisant" otherwise
4. Display the numbers from 1 to 5 using a loop.
