# Chapter 1 FAQ

## Beginner questions

### What is a variable in Python?
A variable is a name that stores a value, such as a number or text.

### Why do we use variables?
We use variables to store information so we can reuse it later in the program.

### What is the difference between `int` and `str`?
`int` is used for integers like `10`, while `str` is used for text like `"hello"`.

### When do we use `input()`?
We use `input()` when we want the user to provide information while the program is running.

### Why do we use `print()`?
We use `print()` to show information to the user or to debug our code.

### What is the difference between `if` and `elif`?
`if` checks the first condition. `elif` checks another condition if the first one is false.

### Why do we use conditions?
We use conditions to make the program choose different actions depending on data.

## Intermediate questions

### Why is indentation important in Python?
Python uses indentation to define blocks of code, especially in loops and conditionals.

### What is the difference between `for` and `while`?
`for` is often used when the number of iterations is known. `while` continues until a condition becomes false.

### When should I use a loop?
Use a loop when you need to repeat the same action several times.

### Why should I avoid repeating code?
Repeating code makes programs longer and harder to maintain. Variables, loops, and functions help reduce repetition.

## Advanced questions

### Why is Python so beginner-friendly for this topic?
Python uses simple syntax and readable code, which makes it easier to learn variables, logic, and control flow.

### How can I write cleaner conditionals?
Use clear variable names and keep conditions short and readable. Avoid too many nested `if` statements when possible.
