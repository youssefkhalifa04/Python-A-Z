# Chapter 5 - Exercises

This folder contains practical exercises for the fifth chapter of the course.

## How to use
- Read the exercise statements in this file.
- Write your attempts in `attempts.py`.
- Check the correction in `correction.md` only after trying the exercises.

## Exercise 1 - Classes and objects
1. Create a class named `Book`.
2. Give it the attributes `title`, `author`, and `pages`.
3. Add a method that displays the book information.
4. Create two objects and call the method for each one.

## Exercise 2 - Inheritance and polymorphism
1. Create a parent class named `Animal` with a method named `sound`.
2. Create at least two child classes such as `Dog` and `Cat`.
3. Override the `sound` method in each child class.
4. Put the objects in a list and call the same method on each object.

## Exercise 3 - Abstract classes
1. Create an abstract class named `Vehicle`.
2. Add an abstract method named `move`.
3. Create two concrete classes that inherit from it.
4. Implement `move` in each class and test the result.

## Exercise 4 - Encapsulation
1. Create a class named `Student`.
2. Add one public attribute, one protected attribute, and one private attribute.
3. Use a method to display the private data safely.
4. Create getter or validation methods where needed.

## Exercise 5 - Interfaces and polymorphism
1. Create an abstract interface named `PaymentMethod` with a method named `pay`.
2. Create two classes such as `CardPayment` and `CashPayment` that implement it.
3. Put the objects in a list.
4. Call the same method on each object and observe different results.
