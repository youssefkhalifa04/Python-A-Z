# Chapter 5 FAQ

## Beginner questions

### What is a class?

A class is a blueprint for creating objects.

### Why do we use classes?

We use classes to group data and behavior into one organized structure.

### What is an object?

An object is an instance of a class.

### What is inheritance?

Inheritance lets one class reuse the features of another class.

### When should I use inheritance?

Use inheritance when several classes share common behavior and you want to avoid duplicate code.

## Intermediate questions

### What is encapsulation?

Encapsulation means protecting data and controlling how it is accessed.

### Why is encapsulation useful?

It keeps objects safer and makes it easier to change internal implementation later.

### What is polymorphism?

Polymorphism means different objects can respond to the same method name in different ways.

### Why is polymorphism helpful?

It makes code more flexible because the same interface can work with different object types.

### What is an interface in Python?

In Python, interfaces are usually represented with abstract base classes that define required methods.

## Advanced questions

### When should I prefer composition over inheritance?

Use composition when objects should contain other objects rather than inherit behavior directly.

### Why are abstract classes useful?

Abstract classes define a common contract so subclasses implement the required behavior consistently.
