# Chapter 2 FAQ

## Beginner questions

### What is a list?
A list is an ordered collection of items that can be changed.

### Why do we use lists?
We use lists when we need to store many values in one place and access them by position.

### When should I use a tuple?
Use a tuple when you want a fixed collection of values that should not be changed.

### What is the difference between a list and a tuple?
A list is mutable, while a tuple is immutable.

### What is a dictionary?
A dictionary stores data as key-value pairs.

### Why do we use dictionaries?
We use dictionaries when we need to look up values by meaningful names such as `name`, `age`, or `city`.

### What is a set?
A set stores unique values and removes duplicates automatically.

### When should I use a set?
Use a set when you need to keep only unique values and perform operations such as union or intersection.

## Intermediate questions

### Why are lists more common than tuples?
Lists are flexible because you can add, remove, and change items.

### What is slicing?
Slicing lets you access a part of a sequence using indexes like `list[1:3]`.

### Why is order important in sequences?
Order matters when the position of each item has meaning, such as in a list of steps or scores.

### When should I choose a dictionary over a list?
Choose a dictionary when your data has labels or names rather than simple positions.

## Advanced questions

### Why are sets useful for performance in some cases?
Sets are efficient for membership tests and for removing duplicates quickly.

### How do I choose between list, tuple, dictionary, and set?
Use a list for ordered mutable data, a tuple for fixed data, a dictionary for key-based lookup, and a set for unique items.
