# Chapter 4 - Exercises

This folder contains short exercises for the fourth chapter of the course.

## How to use
- Read the exercise statements in this file.
- Write your attempts in `attempts.py`.
- Check the correction in `correction.md` only after trying the exercises.

## Exercise 1 - Basic try/except
1. Ask the user for a number.
2. Convert the input to an integer.
3. Use `try` and `except` to handle invalid input.
4. Print a friendly message when the input is valid.

## Exercise 2 - finally and custom errors
1. Create a function that checks if a number is positive.
2. Raise a `ValueError` if the number is negative.
3. Use `try`, `except`, and `finally` when calling the function.
4. Print a message in `finally` to show that cleanup always happens.
