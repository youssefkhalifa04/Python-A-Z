# Chapter 6 - Exercises

This folder contains beginner-friendly exercises for unit testing.

## How to use
- Read the exercise statements in this file.
- Write your attempts in `attempts.py`.
- Check the correction in `correction.md` only after trying the exercises.

## Exercise 1 - Testing a calculator
1. Create a function named `multiply`.
2. Create a test class using `unittest`.
3. Test that `multiply(3, 4)` returns `12`.
4. Test that `multiply(0, 5)` returns `0`.

## Exercise 2 - Testing validation
1. Create a function named `is_adult` that returns `True` when the age is 18 or more.
2. Create a test class for it.
3. Test at least one valid case and one invalid case.
4. Use clear test method names.
