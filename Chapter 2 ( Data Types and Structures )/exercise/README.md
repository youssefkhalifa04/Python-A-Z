# Chapter 2 - Exercises

This folder contains short exercises for the second chapter of the course.

## How to use
- Read the exercise statements in this file.
- Write your attempts in `attempts.py`.
- Check the correction in `correction.md` only after trying the exercises.

## Exercise 1 - Lists, tuples, and sequences
1. Create a list named `colors` with at least 4 colors.
2. Add one more color to the list.
3. Print the first and last items of the list.
4. Create a tuple named `point` with two numbers.
5. Show how lists and tuples are both sequences by using indexing or slicing.

## Exercise 2 - Dictionaries and sets
1. Create a dictionary named `student` with keys like `name`, `age`, and `course`.
2. Update one value in the dictionary.
3. Add a new key-value pair.
4. Create a set with some repeated values and show that duplicates are removed.
5. Display one set operation such as union or intersection.
